# MatchLens starter website

A fresh, responsive, black-and-gold MatchLens landing page.

## Files
- `index.html` — page structure and sample sections
- `styles.css` — responsive styling
- `app.js` — small browser-side script

## Important
The match card is sample content, not a live fixture. No live-score or news API is connected yet.

## Deploy
This is a static website and can be deployed to Vercel:
1. Create a new GitHub repository, for example `matchlens`.
2. Upload the contents of this folder to the repository (not the ZIP file itself).
3. In Vercel, choose **Add New → Project** and import the new repository.
4. Keep the framework preset as **Other**. No build command or output directory is required.
5. Deploy.

You can also test it by opening `index.html` in a browser.
